\section{Anexo: Repositorio del proyecto}

El código completo del proyecto, incluyendo las cuatro implementaciones de procesamiento (Polars, Dask, Modin, Spark), la infraestructura Terraform, los notebooks de exploración, los programas de Hadoop MapReduce, la evidencia recolectada y este mismo informe en LaTeX, está publicado en el siguiente repositorio de GitHub:

\begin{center}
\url{https://github.com/KarTaGo124/Big-Data-Project-I}
\end{center}

\begin{itemize}
    \item \texttt{processing/}, implementaciones de las 12 consultas en Polars, Dask, Modin y Spark.
    \item \texttt{terraform/}, infraestructura de GCP como código (bucket, clúster Dataproc, Cloud NAT, Cloud Scheduler).
    \item \texttt{hadoop-mapreduce/}, resultados y documentación de los tres programas de Hadoop.
    \item \texttt{docs/evidencia/}, capturas y logs de las corridas sobre el clúster real.
    \item \texttt{docs/informe/}, código fuente de este informe.
\end{itemize}
